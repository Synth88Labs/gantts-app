How to Make a Gantt Chart in Word: Three Methods, Step by Step

Microsoft Word was built to write documents, not to schedule projects, yet a Gantt chart is often exactly what a report, a proposal or an assignment needs. You can build one in Word with no add-in, and there are three honest ways to do it. This guide walks through all three, shows the small trick that makes the bars line up, and is clear about the point where Word starts to fight you.

By Uttam Regmi26 August 2026

Can you make a Gantt chart in Word?

Yes. Word has no Gantt chart button, but it has a chart engine, tables and drawing tools, and any one of them can produce a readable timeline. Which route is best depends on how many tasks you have and how often the plan will change.

Three methods cover almost every case:

  • A stacked bar chart, the closest thing to a real Gantt chart and the method most guides describe.
  • A table you shade by hand, the fastest route for a handful of tasks in a document you are already writing.
  • Drawn shapes, the most control and the most manual work.

Whichever you pick, switch the page to landscape first (Layout, Orientation, Landscape) so the timeline has room to breathe. If you would rather skip the whole thing, a free online Gantt maker exports the finished chart straight into a Word document as a picture.

Method 1: The stacked bar chart

This is the method worth learning, because it produces a chart that redraws when you edit its data. It rests on one trick: a Gantt bar is really two bars stacked end to end. The first is a spacer that pushes the bar out to its start date, and you make it invisible. The second is the visible bar, and its length is the task duration.

  1. On the Insert tab choose Chart, pick Bar, then Stacked Bar, and select OK. Word opens a small spreadsheet.
  2. Replace the sample data with three columns: Task, Start (the offset in days from your project start) and Duration (the length in days). One task per row.
  3. Close the data window. Click any bar in the Start series, the first coloured segment of every bar, then set its fill to No Fill. The spacers vanish and only the duration bars remain, each starting on the right day.
  4. Click the vertical axis, open Format Axis, and tick Categories in reverse order so the first task sits at the top, the way a Gantt chart reads.
  5. Tidy up: delete the legend, add a title or data labels, and recolour the bars by phase if you like.

The pay-off is that changing a Start or Duration value in the chart data moves the bar. The cost is that Word measures the axis in plain numbers, not calendar dates, so you work in "days from the start" rather than real dates, and weekends do not exist. Method 2: A table you shade by hand

When you have only a few tasks and the chart lives inside a document you are already writing, a table beats a chart. Each row is a task and each column is a time unit, a week or a day, and you fill the cells a task spans.

  1. Insert a table (Insert, Table) with one column for task names and one column per time period across the top.
  2. Type the task names down the first column and the dates or week numbers across the header row.
  3. For each task, select the cells it spans and apply a Shading colour from the Table Design tab.
  4. Use a second colour, or a single character such as a diamond, to mark milestones and deadlines.

A shaded table has no maths behind it, which is both its strength and its weakness. Nothing recalculates, so it never surprises you, but nothing moves when a date slips either: you re-shade by hand. It is a good fit for a student timeline or a one-page status update.

Method 3: Drawn shapes for full control

The third method uses Insert, Shapes to draw a horizontal line for the axis and a rectangle for each task bar. You place and size every element yourself, so it can look exactly as you want, including the dependency arrows the other two methods cannot draw.

It is also the most laborious, and nothing holds the picture together: move one bar and the rest stay put. Reserve this for a polished one-off, a slide-style timeline for the front of a proposal, rather than a plan you expect to maintain. SmartArt has a couple of timeline layouts that automate part of it if you want a head start.

Which method should you use?

The right method is the one whose weaknesses you can live with for this particular document.

Is there a Gantt chart template for Word?

There is no official Gantt chart template built into Word, and the timeline graphics sometimes offered as "templates" online are static pictures you cannot reschedule. In practice you have two realistic options.

The first is to build the stacked bar chart once and reuse it: save the file as a Word template (.dotx) so the chart, colours and layout are ready next time and you only swap the data. The second, faster if you want dependencies and a critical path already wired in, is to start from a ready-made Gantt chart template, change the names and dates, and export the finished chart into your document. The Excel route gives you a reusable, date-aware template in the same spirit.

A worked example: turning dates into bar lengths

The stacked bar chart wants numbers, not dates, so the step that trips people up is converting a schedule into offsets and durations. Here is a six-task launch plan worked through.

Pick the earliest start as day 0. For every task, the Start value is the number of days from day 0 to that task, and the Duration is its length. Weekends count as ordinary days, because Word does not know about them.

Worked example: a plan running from 1 September.
  • Research, 1 to 5 Sep: Start 0, Duration 4
  • Outline, 6 to 9 Sep: Start 5, Duration 3
  • First draft, 10 to 20 Sep: Start 9, Duration 10
  • Review, 21 to 23 Sep: Start 20, Duration 2
  • Revise, 24 to 28 Sep: Start 23, Duration 4
  • Publish (milestone), 29 Sep: Start 28, Duration 0
Type those two number columns into the chart data and every bar lands on the correct day.

If recomputing those offsets by hand every time a date moves sounds tedious, that is the honest limitation of the approach, and the reason a purpose-built tool exists.

What a Gantt chart in Word cannot do

Every method above draws a picture of a schedule. None of them computes one, and that is the real boundary. In Word there are no task dependencies, so nothing links "testing" to the end of "development"; if development slips, testing sits exactly where you left it. There is no critical path, so the chart cannot tell you which tasks actually drive the finish date. And because the axis counts plain days, weekends and holidays are invisible.

The practical result: a Word Gantt chart is excellent for communicating a plan and poor for maintaining one. While the schedule is stable and you are mostly presenting it, Word is fine. Once dates start moving and you are re-shading cells or recomputing offsets, the document is working against you.

Frequently asked questions

Does Microsoft Word have a Gantt chart template?

Word has no built-in Gantt chart template, but it has the tools to make one: a stacked bar chart, a table, or drawn shapes. Office templates online occasionally offer a static timeline graphic, but it is not a true, editable Gantt chart.

Is it better to make a Gantt chart in Excel or Word?

Excel is better whenever dates will change, because it has a real date axis and formulas, so bar positions can be driven by start and end dates. Word is fine for a fixed timeline inside a written document. See the guide on making a Gantt chart in Excel.

How do I make the bars start on different dates in Word?

Use a stacked bar chart with two series: a Start series holding the offset in days from the project start, and a Duration series. Set the Start series fill to No Fill so it becomes an invisible spacer, and only the duration bars show, each beginning on its own date.

Can I show task dependencies in a Word Gantt chart?

Not automatically. The chart and table methods cannot draw dependency links, and the drawn-shapes method lets you add arrows by hand but they do not move with the tasks. For real dependencies and a critical path, use a dedicated Gantt tool.

How do I put a Gantt chart into a Word document quickly?

Build it in a free online Gantt maker, export it as a PNG or copy the chart, then paste it into your document. You get a clean, correctly dated chart without wrestling with the chart engine in Word.
